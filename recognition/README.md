# Recognition photos

Drop press / recognition photos here. The homepage's "In the community" section currently expects:

- **`collector-jhalawar.jpg`** — Saarthi team with the Jhalawar District Collector & District Magistrate. Recommended size: 1200×900 (4:3) or wider, JPEG, ≤300 KB.

If the file is missing, the homepage `<img>` will render as a broken-image placeholder with a grey background until you drop the real photo at `/recognition/collector-jhalawar.jpg`.
